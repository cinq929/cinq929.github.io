# 交大宿舍共创

发现身边的空间，一起改善宿舍生活。面向上海交通大学学生实践小组的本地网站演示，支持学生与宿管以自选演示角色共同参与。

## 校园活动、个人中心与交大家园

- `#/activities`：参照最新图 1，左侧大校园插画，右侧近期活动，下方活动介绍及分类。示例为校园夜跑、团扇制作、一起包饺子，支持详情、本地报名与取消。
- `#/profile`：参照最新图 2，头像资料与设置、四个快捷入口、校园插画横幅。可查看/取消本地预约、查看/取消报名、查看收藏及演示通知；编辑资料保存后返回个人中心。没有接入账号或真实学籍，不提供真实登录退出。
- `#/community`：扩展首页动态为完整交大家园，四个栏目为“宿”说安全、校园活动、五星宿舍、学业辅导。支持分类、发布动态、评论、点赞、收藏；保留原共创广场 `#/plaza` 的独立入口。
- 首页四栏目及三项活动与新页面共用内容，点赞、评论、预约、报名和收藏可跨页查看。初始动态、互动数量、活动日期/地点/报名状态均为演示；“五星宿舍”不代表官方评选。
- 社区动态、评论、收藏使用 `sjtu-campus-community-v1`；报名、点赞、通知已读沿用名片的 `sjtu-campus-profile-v1`。全部仅保存在当前浏览器，不上传组织者或学校。
- 重要文件：`campus.js`、`campus.css`、`portal.js`、`app.js`；验证见 [QA-campus-pages.md](QA-campus-pages.md)。未新增依赖。

## 宿舍服务：地图、预约与生活进度

- 侧边栏“宿舍服务”进入完整页面 `#/services`，按最新手绘布局组织：大地图 → 活动室预约情况与时间轴 → 洗澡排队、洗衣进度。
- 配色与首页统一：深灰文字、暖白卡片，薄荷绿仅点缀空闲/进度，杏色表达演示占用/维护，淡蓝灰用于洗衣设备；不使用通篇绿色文字和底色。
- 首页“选择宿舍 → 查看全部”进入 `#/services?mode=dorms`，在手绘地图点击楼栋，再“设为当前宿舍”。姓名保留，换楼清空房间号，首页与个人资料同步并在刷新后保留。
- 地图复用项目已有的交大人文地图参考图；支持楼栋/活动室筛选、搜索、空结果、放大缩小、点位详情与官方地图外链。叠加点位仅为交互演示，非实际测绘，不代表真实楼栋拥有这些设施或跨楼使用许可。
- 点击活动室联动预约表；今天、明天、后天分别展示 3 间演示活动室的 2 小时时段与时间轴。填写用途及人数后保存本地预约，支持取消并释放演示时段，拒绝重复预约同一时段。首页“立即预约”也接入这份记录（演示党团活动室 B）。
- 洗澡显示按楼栋切换的演示排队、等待与高峰情况；洗衣显示洗衣中、空闲、维护三种状态，支持本地关注，以及“推进 5 分钟演示”查看洗衣结束后的空闲状态。刷新/切换楼栋会重置进度模拟；关注记录保留，暂不发送通知。
- 新的预约与关注记录保存在 `sjtu-campus-services-v1`，没有真实申请、机器控制或多人同步。旧版首页已存在的 `sjtu-campus-profile-v1` 预约记录保留，之后的新预约统一存服务模块。
- 主要文件：`services.js`、`services.css`、`portal.js`、`app.js`；素材 `assets/reference-ui/campus-culture-map.jpg`。无需新增依赖。桌面验证见 [QA-services.md](QA-services.md)。

## 问题反馈与全屏布局

- 侧边栏“问题反馈”进入 `#/feedback`：左侧列表，右侧详情、处理时间线、宿管演示回复和星级评价。
- 支持状态筛选、关键词搜索、每页 5 条的真实分页、提交新反馈、补充情况、现场图片上传/查看；已解决的演示反馈可以评价，待处理与处理中不能评价。
- 新反馈、补充、压缩后的图片与评价存入 `sjtu-campus-feedback-v1`，刷新保留；没有发送给学校或宿管。新增与补充不会自动解决问题；保存失败会提示并保留表单。
- 五个匿名案例依据用户提供的访谈整理：活动室占用、外卖取餐、聚餐清理、浴室高峰、垃圾混投。日期、处理状态、宿管回复和已解决案例均为虚构演示，访谈未提供处理成果；受访样本与时段有限。
- 首页、资料页和反馈页采用占满浏览器的布局，移除外侧装饰背景及展示留白；底部保留简短演示提示。左上角统一使用用户新提供的红色校徽和中英文校名图片，保留透明背景及原始比例。
- 主要实现文件：`feedback.js`、`feedback.css`、`portal.js`、`portal.css`，验证记录见 [QA-feedback.md](QA-feedback.md)。没有引入新依赖。

## 运行

无需安装第三方依赖。当前环境已使用 Node.js v24.14.1 运行验证。

```powershell
cd D:\思源二面
npm start
```

打开 http://127.0.0.1:3000 。终端按 Ctrl+C 停止。修改源码后刷新浏览器查看；没有热更新。需要其他端口时可用 `$env:PORT = '3001'; npm start`。

```powershell
npm run check
```

此命令检查应用、视图和本地服务的 JavaScript 语法。浏览器流程验证结果见 [QA.md](QA.md)。按用户最新要求，仅验证桌面网页端；保留响应式样式，未进行手机端验收。

## 页面与操作

- 首页 `#/`：最新参考图对应的校园服务仪表盘，首次进入需要填写校园名片。
- 空间地图 `#/spaces`：等距空间剖面示意、搜索、4 类用途、同步列表、点位详情、缩放与重置；可打开交大官方地图。
- 空间详情 `#/space/s1`：设施、位置、适用用途，以及标为待核实的时间、使用人群、预约和权限；反馈自动带入空间名称。
- 共创广场 `#/plaza`：共创画布与议题列表、类别和 5 种进展筛选、真实本地新增议题。
- 议题详情 `#/topic/t1`：问题、各方补充、AI 建议演示、共同确认的行动卡、参与分工、进展回看。

行动卡包含改善目标、下一步行动、参与分工、需要谁确认、回看时间和判断有效的方法。生成 AI 建议不会自动创建行动卡；主动勾选确认后才创建“待确认”行动卡，且不代表管理许可。参与和提出办法不改变解决状态。进展状态只在用户主动填写依据并提交后改变。

## 演示边界

内置 6 个虚构演示空间、4 个演示议题。所有空间插画、剖面、角色、初始人数和进展都是演示。空间图不是真实建筑平面或导航地图；没有把开放规则、预约方式或跨楼使用权限绑定到真实宿舍楼。

AI 使用按议题类别匹配的预设建议，同时呈现当前问题与最近补充。未调用真实模型。尚未接入学校统一认证、真实预约、消息通知、后台审核、管理许可或多人同步服务。

新增议题、评论、建议、参与、反馈与行动记录保存在当前浏览器的 localStorage，键为 `sjtu-dorm-demo-v1`。它们不会发送到服务器、学校或宿管。刷新可保留，清理站点数据会移除；不同浏览器、隐私模式、端口和 `localhost` / `127.0.0.1` 属于不同存储环境。存储失败会提示并阻止声称提交成功。
